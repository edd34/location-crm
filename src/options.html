📊 Notion

Requis

Permet de sauvegarder vos fiches de location et d'ajouter les points d'intérêt en commentaire.

Créée sur notion.so/my-integrations. Veillez à cocher la capacité "Insert comments".
Les 32 caractères dans l'URL de votre base Notion après le nom d'espace et avant le ?v=.... N'oubliez pas d'inviter votre intégration sur la base (menu ... > Connexions).

✨ Intelligence Artificielle (OpenRouter)

Optionnel

Utilisé par le bouton AI Fill pour extraire automatiquement les caractéristiques de l'annonce immobilière.

Disponible sur openrouter.ai/keys.

🗺️ Google Maps

Optionnel

Permet de calculer le temps de trajet vers votre travail et de géocoder l'adresse pour les points d'intérêt.

Générée depuis la Google Cloud Console avec les API Directions API et Geocoding API activées.
Point de repère utilisé pour calculer les temps de transport en commun et en voiture.
💡 Les modifications sont enregistrées automatiquement en local.
